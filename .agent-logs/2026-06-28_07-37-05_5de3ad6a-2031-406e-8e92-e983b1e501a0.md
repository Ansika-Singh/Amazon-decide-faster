That error is happening because of a strict browser security rule called **Mixed Content Blocking**. 

Because you are using the live Vercel website (which is hosted securely on `https://`), your web browser (Chrome/Edge/Safari) will completely block it from trying to communicate with a local, non-secure server like your Ollama instance (`http://localhost:11434`). 

To use the Local Ollama feature, you must run both the website and Ollama on your local machine so they can talk to each other without the browser blocking it.

Here is exactly how to fix it:

### Step 1: Start Ollama correctly
Open your terminal and run Ollama with the origins flag to allow cross-origin requests:
**On Windows (PowerShell):**
```powershell
$env:OLLAMA_ORIGINS="*"; ollama run llava
```
**On Mac/Linux:**
```bash
OLLAMA_ORIGINS="*" ollama run llava
```

### Step 2: Run the website locally
Open a second terminal window in your `Textile Sight` project folder and start the local development server:
```bash
npm run dev
```

### Step 3: Use the local website
Open **`http://localhost:5173`** in your web browser. 

Because the website is now running locally on `http://` instead of Vercel's `https://`, the browser's Mixed Content security won't trigger, and you'll be able to successfully connect to Ollama and run the analysis!
