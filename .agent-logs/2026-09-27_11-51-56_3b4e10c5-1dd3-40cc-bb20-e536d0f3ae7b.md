1. **Unbounded Reasoning Token Budget Truncating JSON**:
   - Groq’s `openai/gpt-oss-120b` generates reasoning tokens before outputting structured JSON. Low token limits caused the reasoning stage to exhaust the budget, abruptly truncating the JSON payload (`failed_generation: "{"`).

   - Refined quota parsing to strictly detect `on tokens per day (TPD)` / `on requests per day (RPD)`.
   - Increased the maximum retry backoff window from 4s to 15s to allow Groq rate-limit windows to reset completely before retrying.

3. **Fallback & Array Resilience Across Engine Steps**:
